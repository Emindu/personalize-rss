This feed is built from Markdown files in the `notes/` folder of this repository.

## Adding a note

1. Create a new `.md` file in `notes/` (on GitHub: **Add file → Create new file**).
2. Commit it to `main`.
3. About a minute later it appears in the feed.

Front matter is optional. Without it, the title comes from the first `# heading`
or the file name, and the date from the last commit.
